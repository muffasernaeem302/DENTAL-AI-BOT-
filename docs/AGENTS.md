# DentalAI AI Agents

## Overview

DentalAI uses AI agents as intelligent assistants for administrative and informational tasks. The agents are designed to enhance patient experience and support dental professionals without making medical decisions.

## Core Principles

### What AI Agents CAN Do
- Answer general questions about dental care
- Help schedule and manage appointments
- Provide pre-visit information
- Generate visit summaries for dentists
- Collect patient information
- Offer oral hygiene guidance

### What AI Agents CANNOT Do
- Diagnose dental conditions
- Prescribe treatments
- Replace qualified dental professionals
- Make medical recommendations
- Interpret X-rays or test results

## Available Agents

### 1. Patient Assistant Agent

**Purpose**: Assist patients with inquiries and scheduling

**Capabilities**:
- Answer general dental questions
- Provide appointment information
- Help with pre-visit preparation
- Offer oral hygiene tips
- Direct to appropriate resources

**System Prompt Guidelines**:
```
You are a helpful dental clinic assistant.
- Be friendly and professional
- Use simple language
- Avoid medical jargon
- Always recommend consulting a dentist for specific concerns
- Never make medical diagnoses
```

### 2. Summary Generator Agent

**Purpose**: Generate patient visit summaries for dentists

**Capabilities**:
- Analyze patient history
- Summarize visit notes
- Extract key observations
- Identify follow-up needs
- Generate recommendations

**Output Format**:
```markdown
## Patient Summary

### Overview
[General patient health summary]

### Key Observations
- [Observation 1]
- [Observation 2]

### Medical Considerations
- [Allergies, conditions, etc.]

### Follow-up Recommendations
1. [Recommendation 1]
2. [Recommendation 2]

---
*Generated by DentalAI - For dentist review only*
```

## Agent Architecture

### Base Agent Class

```python
class BaseAgent(ABC):
    name: str
    description: str
    tools: List[BaseTool]
    
    async def process(message: AgentMessage) -> AgentMessage
    async def call_tool(tool_name: str, **kwargs) -> Any
```

### Tool System

Agents have access to tools that extend their capabilities:

| Tool | Purpose |
|------|---------|
| `schedule_appointment` | Create new appointments |
| `find_appointments` | Search available slots |
| `get_patient_info` | Retrieve patient data |

## Agent Orchestration

The `AgentOrchestrator` class routes requests to appropriate agents:

```python
orchestrator = AgentOrchestrator()

# Route to default agent
response = await orchestrator.route("I need an appointment")

# Route to specific agent
response = await orchestrator.route(
    message="Generate patient summary",
    agent_type="summary_generator"
)
```

## Safety Guidelines

### Input Validation
- All user inputs are validated
- Medical-related requests are filtered
- Dangerous requests are blocked

### Output Filtering
- Responses checked for medical claims
- Recommendations include "consult your dentist"
- Disclaimer added to all responses

### Rate Limiting
- Prevent spam/abuse
- Protect AI resources
- Ensure fair access

## Integration Points

### API Endpoints
- `POST /api/v1/chat` - Send message to Patient Assistant
- `POST /api/v1/summary` - Generate patient summary

### Frontend Services
```typescript

// Summary service

```
